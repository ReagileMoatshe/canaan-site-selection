The Platform

One system, from raw land to investment decision.

Every score CANAAN produces is traceable back to real geography, real resource data, and a real financial model — not a black box.

01

Suitability Scoring

Ranks candidate land by proximity to grid infrastructure, protected-area exclusions, and terrain — turning weeks of manual GIS review into minutes.

02

Resource Forecasting

Projects future solar and wind resource availability at each site using time-series modeling, so decisions are based on tomorrow's yield, not just today's.

03

Return Prediction

Converts forecasted resource data into a plain investment answer — payback period and ROI category — before a single feasibility study is commissioned.

How It Works

A pipeline, not a guess.

Each stage feeds the next — the order matters, because each score depends on the one before it.

01

Ingest land & resource data

Public solar/wind, land-use, and grid-infrastructure data are cleaned into one structured view per candidate region.

02

Score geographic suitability

Spatial analysis flags exclusions and ranks sites by proximity and terrain fit.

03

Forecast the resource

A time-series model projects future irradiance or wind speed at each viable site.

04

Predict the return

Forecasted yield and site features feed a trained model that outputs an ROI category and payback estimate.

05

Deliver the decision

Results surface in a live dashboard — ready to act on, not buried in a spreadsheet.
