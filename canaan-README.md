# CANAAN: Renewable Energy Site-Selection & ROI Platform

A decision-support concept that takes a renewable-energy investor from raw land to an investment decision: site suitability scoring, resource forecasting and return (ROI) prediction.

**Status:** front-end prototype (single HTML page) showing the product concept.

## My role
Team project. I was responsible for data collection and cleaning, GIS suitability scoring, project structure and documentation.

## Tools
Python, GeoPandas (suitability scoring), LSTM (ROI forecasting), HTML/CSS/JS prototype.
